# FootprintESG Antigravity Rules

Inspect the repository before editing. Follow Ponytail: understand the real code path, reuse existing solutions, prefer standard/native features, avoid unnecessary dependencies, and implement the minimum complete solution with tests. Never remove validation, authorization, safe error handling, data-loss protection, accessibility, or tests. Never invent routes, schemas, emission factors, test results, integrations, or compliance claims. Enforce server-side organization/facility authorization. Persist valid readings before Socket.IO broadcasts. Invalid readings must not update current state. Keep live snapshots separate from history; missing data is not zero. Manual data is official only after approval; never silently overwrite approved records. Preserve emission-factor provenance. MVP is MERN + REST/JSON + Socket.IO, energy/water/waste/production and Scope 1/2. AI/ML prediction, Scope 3, physical IoT, SCADA, ERP and mobile are out of scope. Report exact files, checks run/results, skipped checks, and risks.
