# FootprintESG Antigravity Handoff

Copy `AGENTS.md`, `project.md`, `prd.md`, `srs.md` and `skill.md` to the root of the FootprintESG repository.

- `AGENTS.md`: always-on workspace rules using Ponytail principles.
- `project.md`: scope, architecture, implementation phases and definition of done.
- `prd.md`: user needs, workflows and acceptance criteria.
- `srs.md`: functional/non-functional requirements, data/API/security/test rules.
- `skill.md`: repeatable coding-agent workflow.

First task for the agent: audit the actual repository and report a baseline map plus prioritized gap analysis before broad edits. These docs describe intended behavior; they do not prove existing implementation status. Register `skill.md` through Antigravity's documented skill mechanism if supported; do not assume filename-based discovery.
